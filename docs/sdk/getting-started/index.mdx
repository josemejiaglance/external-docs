# Getting Started

Integrate the Glance Default UI SDK into an existing iOS app in two steps: **install the package** and **configure initial settings**.

<Steps>
### Install the SDK

Add `GlanceDefaultUI` via Swift Package Manager or embed XCFrameworks directly. `GlanceSDK` is pulled in automatically when using SPM.

[Installation →](./installation)

### Configure the SDK

Set visitor params and assign a delegate before starting any session.

[Initial Setup →](./setup)
</Steps>

## Prerequisites

- iOS 15 or later
- Swift 5.7 toolchain (`swift-tools-version: 5.7`)
- A valid Glance group ID (from your Glance admin portal)
- Network access to Glance services
