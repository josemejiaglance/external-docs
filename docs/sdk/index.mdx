# Glance Default UI – iOS SDK

**Glance Default UI** (`GlanceDefaultUI`) is an out-of-the-box cobrowse package for iOS that layers a complete session UI on top of GlanceSDK. It ships ready-made dialogs for session consent, session key display, video, Presence (1-Click Connect), and hosted sessions — so you spend minutes integrating, not days building UI.

## What's included

- App Share consent and session-key dialogs
- Video consent dialog with camera preview
- Presence (agent-initiated) terms dialog
- Hosted session key display and error handling
- Keyboard and background masking out of the box
- Fully localizable string constants

## Requirements

| Requirement | Value |
|---|---|
| iOS | 15+ |
| Swift Tools | 5.7+ |
| GlanceSDK | ≥ 7.2.0 (pulled in automatically via SPM) |
| Permissions | Network; Camera + Microphone only if using video |

## Version notes

<Callout type="info">
**v7.2 (current):** `setVisitorParams` no longer accepts `fetchSettingsInterval`. To enable remote settings, call `Glance.enableSettings(isEnabled: true)` (1-hour refresh) or `Glance.setSettingsAPIRefreshInterval(refreshInterval:)` for a custom interval. `GlanceError.code` is now typed as `GlanceSDKEventCode`.

**v7.1:** `setVisitorParams` accepts `fetchSettingsInterval: GlanceDefaultUI.SettingsInterval`. `GlanceError.code` is typed as `EventCode`.
</Callout>
