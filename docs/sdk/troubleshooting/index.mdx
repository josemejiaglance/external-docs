## Quick diagnostics checklist

Before diving into a specific article, verify these common causes:

1. **`setDelegate` called before `start()`?** — Delegate must be assigned before any session method.
2. **`setVisitorParams` called with a valid `groupid`?** — A zero or missing group ID silently prevents sessions from starting.
3. **`onError` implemented and wired to UI?** — Many failures surface through `onError` but are silently dropped if the method is empty.
4. **Network accessible?** — The SDK requires connectivity to Glance services.
5. **Correct `videoMode` syntax?** — Use `videoMode: VideoOff`, not `.VideoOff`.
