# Localization Constants

`GlanceLocalizedStringsConstants` is a struct of `static let` string constants. Each constant holds the key used to look up localized text in `Localizable.strings`. Override any key in your app bundle to customize the displayed string.

```swift showLineNumbers
import GlanceDefaultUI

// Access a constant
let titleKey = GlanceLocalizedStringsConstants.defaultUIStartDialogTitle
```

See [Localization guide](../sdk/guides/localization) for how to override strings and add new languages.

## Error dialog

| Constant | Usage |
|---|---|
| `dialogErrorTitle` | Error dialog title |
| `dialogErrorPrimaryButton` | Primary action button (e.g. "Retry") |
| `dialogErrorSecondaryButton` | Secondary button (e.g. "Dismiss") |

```swift showLineNumbers
// Example usage in a hosted session error alert
Alert(
    title: Text(GlanceLocalizedStringsConstants.dialogErrorTitle),
    message: Text(viewModel.errorMessage),
    primaryButton: .default(
        Text(GlanceLocalizedStringsConstants.dialogErrorPrimaryButton)
    ),
    secondaryButton: .cancel(
        Text(GlanceLocalizedStringsConstants.dialogErrorSecondaryButton)
    )
)
```
