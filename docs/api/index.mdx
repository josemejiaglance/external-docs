## Version differences

| Feature | v7.1 | v7.2 |
|---|---|---|
| `setVisitorParams` `fetchSettingsInterval` param | `GlanceDefaultUI.SettingsInterval` | Removed — use `Glance.enableSettings` |
| `GlanceError.code` type | `EventCode` | `GlanceSDKEventCode` |
| Remote settings | Via `setVisitorParams` | `Glance.enableSettings(isEnabled:)` / `Glance.setSettingsAPIRefreshInterval` |
